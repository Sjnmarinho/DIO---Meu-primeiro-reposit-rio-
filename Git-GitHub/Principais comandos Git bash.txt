# 📌 Comandos básicos do Git bash

- `git init` → Inicializa um repositório Git.
- `git clone <url>` → Clona um repositório remoto.
- `git status` → Mostra o estado dos arquivos no repositório.
- `git add <arquivo>` → Adiciona um arquivo ao stage (preparar para commit).
- `git add .` → Adiciona todos os arquivos modificados.
- `git commit -m "mensagem"` → Cria um commit com as mudanças.
- `git log` → Mostra o histórico de commits.
- `git branch` → Lista as branches.
- `git checkout -b <nome-da-branch>` → Cria e muda para uma nova branch.
- `git merge <branch>` → Faz merge de uma branch na atual.
- `git push origin <branch>` → Envia commits para o repositório remoto.
- `git pull` → Atualiza o repositório local com o remoto.
